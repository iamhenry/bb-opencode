# UX behavior

## Current UX

1. A Task appears as BB's native delegation row.
2. Child tools are nested under it.
3. Child assistant text/reasoning can also enter the nested activity stream, competing with the Task's terminal Output and risking duplicate final content.
4. A running child may also be opened as a native BB child thread.

## Post-change UX

1. A Task remains BB's native delegation row with its requested task label.
2. BB shows the bounded recent nested operational events and owns its existing “more” disclosure.
3. Child prose/reasoning does not appear as activity rows.
4. On completion, the Task result appears once through BB's native Output disclosure.
5. Missing child metadata leaves the ordinary Task row and parent chat usable.
